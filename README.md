# minus-phone.github.io

Il sito di **−minus**, launcher minimale per Android, gratis e open source.

È una pagina sola, statica: `index.html` con i caratteri in locale (Literata e Atkinson Hyperlegible, licenza SIL OFL, in `fonts/`). Nessuno script esterno, nessun tracciamento.

Il codice dell'app è su [minus-phone/Minus](https://github.com/minus-phone/Minus).
